# Codex 작업 이어하기

## 목적

학원 컴퓨터와 집 컴퓨터를 번갈아 사용하거나 새로운 Codex 대화를 시작할 때, 기존 프로젝트의 개발 상태를 파악하고 중단한 작업을 이어가기 위한 프롬프트다.

## Codex 요청문

현재 열려 있는 프로젝트는 희망환급 AI 챗봇 개인 개발 저장소 `uio6236/OllamaChatbot`입니다.

다음 순서로 프로젝트 상태를 확인해주세요.

1. `chatbot/AGENTS.md`와 관련 디렉터리의 `AGENTS.md`를 읽고 개발 규칙을 확인합니다.
2. `chatbot/docs/history.md`와 `chatbot/docs/05_단계별작업계획.md`를 읽고 개발 진행 상황을 파악합니다.
3. 실제 소스 코드와 Git 상태를 확인하여 문서에 기록된 내용이 현재 구현 상태와 일치하는지 검증합니다.
4. 완료된 기능, 진행 중인 기능, 남은 작업을 정리합니다.
5. 이전 작업에서 발생한 오류, 미해결 문제, 추가 검증이 필요한 부분을 확인합니다.
6. 현재 상태에서 다음으로 진행할 작업과 그 이유를 제안합니다.

### 주의 사항

- 이번 요청에서는 어떤 파일도 수정하거나 생성하지 마세요.
- Git commit, push, pull, merge, rebase 등을 실행하지 마세요.
- 기존 코드의 정상 작동 여부를 확인하지 않고 구현 완료로 판단하지 마세요.
- 개발 이력과 실제 코드가 서로 다르면 차이점을 보고해주세요.
- 이전 Codex 대화를 기억한다고 가정하지 말고 저장소의 문서와 실제 코드를 근거로 판단해주세요.
- 분석이 완료되면 결과를 보고하고 다음 작업에 대한 승인을 기다려주세요.
