# 청크 품질 검수·법령 적용·검색 승인 분리 (2026-11-11)

## 구현 범위와 신뢰 경계

기존 PDF 8개와 전처리 v3 청크/manifest는 변경하지 않고 별도 검수 묶음을 생성한다.
구조 검사, 법령 적용 검증, 검색 사용 승인은 독립 상태다. 원문 추출 줄 대조는 내부 정합성 검사이며
추출기가 놓친 시각 영역이나 공식 법령과의 일치성을 증명하지 않는다.
법령 적용은 사람이 실제 공식 본문·부칙/적용례를 확인한 기록이 있어야 한다.
검수 파일은 신뢰하는 검토자가 관리하는 로컬 원장이다. 전자서명·검토자 로그인·다중 사용자 권한 검증은 구현하지 않았다.

## 원장 작성 규칙

`ReviewRecord`는 documentVersion/contentHash/configHash와 chunkId를 묶는다.
초기 기록은 sequence=0, 구조 PENDING, 적용 PENDING/null/false, 사용 HOLD다.
원본 검수 묶음은 보존하고 작업용 원장은 별도 경로에 복사하여 후속 JSONL 기록을 덧붙인다.
새 기록의 sequence는 직전+1, previousReviewId는 직전 reviewId여야 한다. 중복 ID/끊어진 순서는 전체 내보내기를 거부한다.
승인·반려·회수와 후속 기록에는 검토자와 시간대가 포함된 검토일을 기록한다.

- 구조: PENDING/PASS_AUTO/PASS_MANUAL/PASS_SAMPLED/HOLD/REJECT.
- 적용: PENDING/VERIFIED/CONDITIONAL/NOT_APPLICABLE. VERIFIED 외에는 기존 귀속연도 null/false를 유지한다.
- 사용: HOLD/APPROVED/REJECTED/REVOKED. 승인 범위는 CURRENT_2026 또는 EVALUATION_ONLY.
- 승인에는 검수 방식·근거 메모, 법령 본문 RULE 및 적용례 APPLICATION 증거가 필요하다.
- 공식 증거는 실제 확인한 HTTPS law.go.kr/nts.go.kr URL, 위치, UTF-8 본문 스냅샷 파일,
  스냅샷 SHA-256, 원문 인용, reviewed=true를 기록한다. 스냅샷 파일의 경로 이탈·해시 변경·인용문 누락은 차단한다.
- URL 호스트 허용과 해시는 자료의 진위·법률 해석을 자동 보증하지 않는다. 스냅샷을 취득·검토한 사람의 책임을 대체하지 않는다.
- 구조 표본 승인은 고위험 자료에 사용할 수 없으며 적용 검증을 대체하지 않는다.
- 회수/반려/보류는 최신 기록이 우선하며 이전 승인으로 돌아가서 내보내지 않는다.

## 운영 내보내기 정책

승인 없음·원본 변경·본문/설정 해시 변경·구조 차단 신호는 기본 제외다.
PASS_AUTO만으로 승인할 수 없다. 검수 방식/근거가 있는 PASS_MANUAL 또는 저위험 PASS_SAMPLED가 필요하다.
CURRENT_2026 및 2026 VERIFIED, 소득 유형 범위 일치, 검토된 공식 본문/적용례 스냅샷을 모두 요구한다.
조건부 적용은 아직 질의 조건 필터를 구현하지 않아 제외하며, 2025 안내서도 2026 운영 자료에서 제외한다.

개정 비교표 전체 본문은 제외한다. REVISED_WITH_APPLICATION 역할로 원본 줄 ID를 선택해야 하며,
원본 순서를 유지하고 종전 열은 선택할 수 없다. 개정 열과 적용례·경과 표·예외 각주 전체를 포함해야 한다.
적용례가 없거나 비교표 머리글이 모호하면 보류다. 개정 열의 좌동을 독립 문장으로 내보내지 않는다.
좌동은 확인된 현행 법령의 별도 근거로 해결해야 하며 임의 확장 문장을 만들지 않는다.

내보낸 자료는 새 chunkId와 parentChunkId, 선택 본문 해시, 승인 reviewId를 갖는다.
원본 청크의 본문/연도/검증 여부는 수정하지 않는다. 새 출력 디렉터리만 생성하고 기존 출력은 덮어쓰지 않는다.
Elasticsearch·실제 FastAPI 검색기는 연결하지 않는다. 모든 출력은 승인 당시 스냅샷이므로 나중에 회수되면
재내보내기와 기존 색인/캐시 제거가 필요하다. 색인 회수 처리는 다음 단계의 요구사항이다.

## 후속 검토

개정 자료 35개에서 월세·카드·자녀/교육비 비교표·경과규정을 우선 검토한다.
공식 법령 버전과 부칙을 확보해 기록하고, 표 114개 후보 중 핵심/불명확 사례를 먼저 대조한다.
표본 180개는 오류가 발견되면 같은 추출/분할 유형의 검토 범위를 확대한다.
BM25는 승인 자료 확보 후 별도 승인 범위에서 매핑·색인 게이트·정답 근거 묶음과 평가 질문을 구현한다.
