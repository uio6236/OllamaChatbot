# 07. 기능/정확성/보안/통합 테스트 체크리스트

## LangChain/Ollama
- [ ] Ollama 미실행 → 적절한 503 계열 내부 오류; 임의 답변 반환 금지
- [ ] 설치 모델 태그 불일치 → 명확한 내부 오류 및 설정 확인
- [ ] ChatOllama mock 단위 테스트, 실제 로컬 모델 연결 통합 테스트 분리

## API/보안
- [ ] `GET /health` 기존 정상 응답 유지
- [ ] 내부 토큰 누락·불일치 → 401 (본문/로그에 토큰 노출 금지)
- [ ] 빈 질문·1,000자 초과·잘못된 taxYear → 입력 오류
- [ ] 타인 `SESSION_ID` 요청 → 접근 거부 및 AI 호출 발생하지 않음
- [ ] 타인 `PREDICTION_ID` 요청 → 접근 거부 및 AI 호출 발생하지 않음
- [ ] 개발용 `X-Member-Id`를 운영에서 수용하지 않음
- [ ] 사용자에게 DB SQL·스택트레이스·비밀키 노출 없음
- [ ] 개인정보·카드번호가 AI 입력·로그에 불필요하게 노출되지 않음

## 검색/법령
- [ ] 7개 PDF 원본 목록/해시/페이지 추출 검증
- [ ] 핵심 조문(월세, 카드공제, 청년 중소기업 감면) 원문과 텍스트 대조
- [ ] `tax_law_index`만 변경, 가맹점 분류 인덱스 영향 없음
- [ ] 세법 검색 결과 출처/페이지/조문이 실제 문서와 일치
- [ ] 2025 귀속 안내서가 2026 귀속 확정 근거로 오인되지 않음
- [ ] 근거 없는 법령/없는 조문을 만들어 내지 않음
- [ ] 악의적 검색문서 지시문을 시스템 명령으로 따르지 않음

## 계산/첫 안내
- [ ] LLM이 환급액·절세액을 임의 계산/변경하지 않음
- [ ] `PREDICTION` 저장 후 RECOMMENDATION 생성
- [ ] 추천 생성 실패에도 계산 결과 유지
- [ ] 추천 중복 발생 정책 및 재시도 테스트
- [ ] `RECOMMENDATION.TYPE_ID`와 `SAVING_AMOUNT`를 DB/Calc 근거로 검증

## 채팅·이력
- [ ] 새 상담방과 로그인 회원 소유권 연결
- [ ] 사용자 질문과 AI 답변이 각각 `CHAT_MESSAGE`에 적절히 저장
- [ ] AI 실패 시 AI 답변 미저장 (기능명세서)
- [ ] `MESSAGE_ID` 오름차순으로 이력 표시
- [ ] 대화 후 새로고침·재로그인 시 Oracle 이력 복원
- [ ] 직전 상담 내용이 현재 질문의 맥락으로 반영되되 다른 회원의 이력 혼입 없음
- [ ] 계산 결과 없이 질문 가능한 범위는 팀 기능명세에 맞춤
- [ ] 세법 설명은 챗봇에서 제공, 독립 카드 UI 미생성
