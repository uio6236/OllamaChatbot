## 2026-11-09 팀 공통 API 패키징 회귀 테스트
- [ ] React → Spring 단건/목록 응답이 `success,data,meta,error` 네 키로 반환됨
- [ ] 목록 메타 페이지는 1부터 시작하고 `page,size,total,totalPages` 정확함
- [ ] Spring → FastAPI 내부 응답은 **봉투 없이** 순수 JSON DTO 사용
- [ ] UI 공통 `apiRequest()`가 이미 `data`를 추출한 경우 이중 `.data` 접근하지 않음
- [ ] 400 VALIDATION / 401 UNAUTHORIZED / 403 FORBIDDEN / 404 NOT_FOUND / 405 METHOD_NOT_ALLOWED / 409 CONFLICT / 415 UNSUPPORTED_MEDIA_TYPE 상태·코드 검증
- [ ] 500 SERVER_ERROR / 503 CHATBOT_UNAVAILABLE 응답에만 `error.errorId` 존재; 응답·서버 로그의 오류번호 일치
- [ ] 화면에 SQL/스택/토큰/모델 내부 정보 미노출, 서버 로그에 실제 금액·카드번호·비밀번호·민감 질문 미기록
- [ ] Chatbot 연결 실패 시 공통 예외 처리기를 통해 503 봉투 반환, 실패 AI 메시지 미저장
- [ ] 504 타임아웃은 팀의 추가 합의 전 테스트 기대값을 임의 확정하지 않음
- [ ] 실제 공통 컴포넌트가 존재한다면 중복 `ApiResponse`/`GlobalExceptionHandler`를 추가하지 않음
