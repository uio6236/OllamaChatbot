## 기본 방침
- **소유권은 기능 기준:** AI 챗봇 담당자가 `chatbot/` Python 코드뿐 아니라 `backend/chat/`, 필요시 공통 보안 설정, `frontend/` 채팅 연결을 직접 수행한다. 다만 타 기능과 공유하는 코드 변경·API 변경·DB 변경은 팀 PR 검토 대상이다.
- **이미 생성·Clone한 개인 저장소 `OllamaChatbot`을 사용**한다. 새 저장소/`ai/`를 만들지 않고 기존 **`chatbot/`**를 확장한다.
- 기존 React UI를 새로 만들지 않는다. 계산·추천·대화는 가상 체험과 실서비스를 엄격히 구분.
- 소스 기준 **확정**과 아래 문서의 **제안**을 혼동하지 않는다.
- Codex의 첫 요청은 **읽기·분석만**, 구현은 다음 단계에서 한 기능씩 테스트하며 진행한다.
- 이 패키지는 **별도 전달용 참고 문서**다. GitHub에 자동 적용되거나 코드를 수정하지 않았다.
